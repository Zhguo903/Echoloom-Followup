# Data Dictionary

## Run record

`run_id`, campaign/scenario/version, method, provider/model, prompt/config hashes, seed/order, hard-gate trace, optional deliberation, controller overrides, admitted views, visible reply, validator/repair/fallback state, latency/tokens, input/output hashes, serialized generator request, time, and optional commit.

## Memory card

Stable ID and fictional owner/character, bounded content, memory type, provenance, confidence, sensitivity, permission, currentness/correction links, confirmation/inference flags, callback history, branch, qualifiers, sanitized topic, tags, and restrictions.

## Study export

Random participant code, consent/protocol version, assignment/scenario/blinded response IDs, display order, 1–7 measures, optional rationale, skip/withdraw/completion state, and timestamps. Names, emails, private chats, clinical status, and raw sensitive disclosures are excluded.
