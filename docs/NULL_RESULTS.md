# Useful Null and Mixed Results

| Outcome | What can be claimed | Next discriminating test |
|---|---|---|
| No universal action wins | Norms appear contextual in this sample/task | Stratify by memory type and rationale |
| ASK_FIRST feels more intrusive than silence | Permission prompts are not automatically preferable | Directly compare ignore and ask-first under matched warrant |
| Two-pass helps, rubric does not | Selection/separation may explain gains | Factorial ablation of rubric vs separation |
| Prompt-only control varies by model | Reliability is provider-specific | Freeze three-family portability subset |
| Physical separation has no measurable difference | It remains an engineering safeguard, not an empirical contribution | Stronger non-verbatim leakage stress cases |
| Selection improves without experience gains | Computational proxies did not transfer to ratings | Improve response realization and stimulus realism |
| Strongest baseline solves nearly all cases | Contribution has little demonstrated headroom | Narrow scope or construct non-trivial cases before study |
| Full method suppresses useful memory | Misuse reduction came with continuity loss | Retune admission and measure beneficial retention first |
