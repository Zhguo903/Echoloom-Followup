# Blinded Response-Study Protocol

Status: scaffolding only; not approved or active.

Adults confirm eligibility and a versioned consent form before receiving a random participant code. A reproducible incomplete-block generator balances conditions, randomizes response order, avoids duplicate scenario-condition exposure within a session, and stores its seed/manifest.

The participant sees a short synthetic scenario and one or a small matched set of responses. Provider, model, method, audit trace, and preferred-condition cues remain hidden. Primary outcome: relational appropriateness. Secondary 7-point measures: helpfulness, naturalness, continuity, feeling understood, intrusion, creepiness, privacy concern, trust, and agency. An optional short rationale supports disagreement analysis.

Participants may skip any item or withdraw. Withdrawal removes collected responses associated with the random code. Export is de-identified long format with codebook, assignment manifest, exclusions log, and protocol/consent versions.

The primary model treats condition as fixed and participant/scenario as random intercepts. An optional cumulative-link mixed model is a sensitivity analysis. Report estimates, intervals, diagnostics, practical importance, disagreement, exclusions, and null/mixed outcomes.
