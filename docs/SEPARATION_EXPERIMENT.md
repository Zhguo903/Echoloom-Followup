# Physical-Separation Draft Scaffolding

Phase 2 creates 16 stress-test drafts only: two each for wrong user, wrong branch, deleted/do-not-use, superseded/corrected, sensitive canary, callback fatigue, episode-to-identity, and relevant cross-domain influence.

Each draft identifies one rejected card, a unique exact canary, a plain semantic concept, a valid admitted or no-memory response path, and predeclared exact/lexical/blinded-semantic checks. All are `needs_human_review` and unfrozen.

The actual paired runner, request-diff manipulation, model campaign, effect analysis, and null-result interpretation belong to Phase 7 and are intentionally absent. In particular, hard-gated wrong-user, wrong-branch, deleted, and superseded cards must not be made provider-visible merely to manufacture a separation effect. Human review must resolve how those boundary cases are used before any campaign is frozen.
