# Five-Minute Demo Script

**0:00 — Problem.** “Correct recall can still be a poor relational action. Retrieval finds what can be recalled; Reconsider-Lite asks what is worth bringing up now.” Clarify that all content is synthetic.

**0:35 — Record-store case.** Open `/lab/golden_record_store_weekend_v1`. Read the weekend question and briefly identify all four cards: useful episode, unrelated sensitive history, low-value cake preference, and unconfirmed identity inference.

**1:20 — Baseline risk.** Choose one-pass selective or open comparison. Point out that all direct-eligible cards remain serialized for generation even when the prompt says “ignore.” Do not claim this always causes harm.

**2:00 — Full method.** Run Reconsider-Lite. Walk across Validity → Utility → Warrant → Scope → Expression. Brief rationales are audit summaries, not chain-of-thought.

**2:45 — Physical boundary.** Show the admitted record-store view inside the green generator box and rejected items outside. Note the “during one stressful exam week” qualifier and the absence of family-conflict content in the serialized generator context.

**3:25 — Response.** Read the scoped reply. It offers an option without calling the user an introvert, forcing personalization, or revealing the sensitive detail.

**3:55 — Ablation.** Open compare, contrast full method with no physical separation, and expand each trace. The latter deliberately keeps eligible ignored cards visible.

**4:30 — Audit and handoff.** Export run JSON and mention prompt/scenario/config hashes, validators, repairs, and fallback. End: “This demo tests an auditable design mechanism; it is not a universal model of human judgment or evidence of user validation.”
